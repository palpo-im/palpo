## 升级与语义边界

- 未添加数据库迁移；通知锁与 shared sync cache 的新语义需要协调升级相关节点。见 [UPGRADING](../UPGRADING.md)。
- 本地 OIDC 的可信客户端列表默认空；未知目标被拒绝。原生回调精确路径规则也用于 delegated SSO。见 [SSO 配置](../development/sso-client-redirects.md)。
- 全局资料先提交、房间逐个提交；失败需要同值重试，没有自动全局回滚。已匹配的成员事件可按原 ID 再次排队，成功不等于远端已经 ACK。见 [资料传播](../development/profile-propagation.md)。
- 通知计数故障测试覆盖函数事务和明确重试，不能推导成所有 post-publication 派生工作已有后台自动修复。
- 本轮修复推送的成员权限边界；不承诺撤销阅读前已经排队的每一条推送。已读计数正确归零与网关投递撤销是两个独立保证。
- 不重建过去已经被错误阅读标记删除的通知，不恢复旧私有回执中已丢失的线程标识，也不撤销修复前已广播的错误阅读位置。连接缓存条目上限不等于任意 required-state 响应的字节上限。
- 本轮未执行 Complement/Sytest 完整互通套件，也未测量生产环境的峰值内存或吞吐。
- 本轮不使用 Docker。构建沿用调用环境与 workspace 正常 target 目录，不更改 Cargo home、target 或 TEMP/TMP，也不引入全局缓存目录。
